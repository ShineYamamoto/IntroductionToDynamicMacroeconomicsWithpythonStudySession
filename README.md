# Pythonで学ぶ動学マクロ経済学 — 勉強会ノート

ソローモデルとRamseyモデルを題材に、Pythonで定常状態の計算と動学シミュレーションを学ぶためのJupyter Notebook集です。資本蓄積の逐次計算から、ニュートン法、対数線形近似、固有値・固有ベクトルを用いた動学分析へと進みます。

## 学習の前提

- Pythonの変数、関数、リスト、繰り返し処理の基礎
- 微分と行列計算の基礎（第3回以降は偏微分、連立一次方程式、第4回は固有値・固有ベクトル）
- 生産関数、資本蓄積、消費、定常状態といったマクロ経済学の基本概念

### 第1回：ソローモデルの定常状態と資本蓄積

**教材：** [python勉強会1.ipynb](./python勉強会1.ipynb)

**学習項目**

- 資本分配率、貯蓄率、資本減耗率、人口成長率の設定
- 定常資本ストックの計算
- 関数 `solow()` と繰り返し処理による資本蓄積式の逐次計算
- Matplotlibによる結果の比較

**実装されている実験：** 初期資本を定常値の0.5倍・2倍とし、それぞれ100期間の推移を計算します。パラメータは資本分配率0.3、貯蓄率0.2、資本減耗率0.1、人口成長率−0.01です。関数の引数 `A` は初期資本を定常値の何倍にするかを表します。

**到達目標：** 資本蓄積の差分方程式をコードに対応づけ、初期値の違いと定常状態への収束をグラフで説明できるようになること。

### 第2回：貯蓄率の変化と資本・消費の反応

**教材：** [python勉強会2.ipynb](./python勉強会2.ipynb)

**学習項目**

- SymPyによる記号の定義とパラメータの代入
- 貯蓄率変更前の定常状態を初期値とする設定
- 資本蓄積と消費を別々の関数として実装する方法
- 変更前の水準を基準線にした時系列の比較

**実装されている実験：** 貯蓄率を0.2から0.3へ引き上げ、120期間にわたって資本と消費を計算します。その他のパラメータは第1回と同じです。

**到達目標：** 貯蓄率の変化が資本蓄積と消費に及ぼす影響を、移行過程と長期的な変化に分けて読み取れるようになること。

### 第3回・手順書：Ramseyモデルの定常状態を求める準備

**教材：** [python勉強会3の手順.ipynb](./python勉強会3の手順.ipynb)

**学習項目**

- 消費のオイラー方程式と資本蓄積式の定義
- 今期と来期の変数が等しいという定常状態の条件
- 2本の方程式のベクトル化
- 消費と資本で偏微分したヤコビ行列の作成
- 多変数ニュートン法の更新式と収束判定の考え方

**教材の形式：** 数式と文章で計算手順を説明するノートです。実行用のコードセルはなく、第3回のコードと照らし合わせて読みます。

**到達目標：** 「モデルの定義 → 定常状態の条件 → ベクトル化 → ヤコビ行列 → 反復計算」の流れを説明できるようになること。

### 第3回・実装：ニュートン法による定常状態の数値計算

**教材：** [python勉強会3.ipynb](./python勉強会3.ipynb)

**学習項目**

- SymPyの `Matrix`、`subs`、`diff` による方程式の操作
- `Jacobian()` によるヤコビ行列の作成
- `np.linalg.solve()` を使ったニュートン法の更新
- 初期値、収束許容誤差、反復回数の上限の設定

**実装されている計算：** 資本分配率0.3、割引因子0.99、資本減耗率0.25のもとで、消費と資本の初期推定値をともに1として定常状態を求めます。収束許容誤差は `1e-15`、反復回数上限の設定値は20です。

**到達目標：** 非線形連立方程式を数値的に解き、定常消費・定常資本の計算過程を追えるようになること。

### 第4回：近似モデルの解法と動学シミュレーション

**教材：** [python勉強会4.ipynb](./python勉強会4.ipynb)

**学習項目**

1. Ramseyモデルを定義し、ニュートン法で定常状態を計算する。
2. 対数線形近似として記述された式から、今期・来期の係数行列を取り出す。
3. 固有値・固有ベクトルを計算し、並べ替える。
4. 消費を非先決変数、資本を先決変数として、行列の分割から政策関数と資本の推移を求める。
5. 定常状態からの対数乖離でシミュレーションし、消費・資本の水準に戻す。
6. 位相図、時系列、対数乖離のグラフを描く。

**実装されている実験：** 初期資本を定常値の0.5倍・2倍に設定して100期分の経路を求め、位相図で比較します。水準の時系列と最後の対数乖離の図は、初期資本が定常値の0.5倍の場合を表示します。

**到達目標：** 定常状態の計算から近似モデルの行列表現、動学経路の可視化までの一連の処理を理解すること。

**読み方の補足：** ノート後半で「インパルス反応」と呼ばれている図は、この実装では初期資本のずれに対する消費・資本の調整経路です。確率的な外生ショックを導入したRBCモデル等の実装は含まれていません。

## 推奨する学習順序

**第1回 → 第2回 → 第3回の手順書 → 第3回の実装 → 第4回**

各回では、まず初期設定と出力を確認し、数式とコードの対応を追ったうえで、パラメータや初期値を一つずつ変えて比較すると理解を深められます。第4回は定常状態の計算コードを含んでいるため、第3回の実行結果を引き継ぐ必要はありません。

## 実行方法

Python 3とJupyter環境を使用します。ノートブックに記録されたPythonのバージョンは3.7.3ですが、ライブラリのバージョン指定はリポジトリに含まれていません。

必要なパッケージをインストールします。

```bash
python -m pip install jupyterlab numpy sympy matplotlib japanize-matplotlib
```

リポジトリを取得し、そのディレクトリでJupyterLabを起動します。

```bash
git clone https://github.com/ShineYamamoto/IntroductionToDynamicMacroeconomicsWithpythonStudySession.git
cd IntroductionToDynamicMacroeconomicsWithpythonStudySession
jupyter lab
```

対象の `.ipynb` を開き、コードセルを上から順に実行してください。第3回の手順書は読むための資料です。

| パッケージ | 用途 | 使用する教材 |
| --- | --- | --- |
| Matplotlib | グラフの描画 | 第1・2・4回（第3回でもインポート） |
| NumPy | 配列、連立一次方程式、固有値計算 | 第2・3・4回 |
| SymPy | 記号計算、代入、微分 | 第2・3・4回 |
| japanize-matplotlib | グラフの日本語表示 | 第4回 |

上記はノートブックのインポートに基づく導入例です。現在のライブラリ環境での動作確認を保証するものではありません。

## 学習時の補足

- 第3回の実装では、方程式の残差の絶対値の和で収束を判定しています。`1e-15` はこの教材で設定した許容誤差であり、Pythonで表現できる最小値ではありません。
- 第4回のニュートン法の説明式は、手順書の逆ヤコビ行列を用いた更新式と併せて確認してください。コードでは `np.linalg.solve()` で更新量を求めています。
- 第4回の近似とシミュレーションは定常状態の近傍を考える学習題材です。定常値の0.5倍・2倍という初期条件で得られる経路は、元の非線形モデルの厳密解とは区別して読み取ってください。
